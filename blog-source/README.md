# Unirazz blog source

Add new articles to `docs/articles/`, following the sample articles as templates. Add each article to the `nav` and `sidebar` entries in `docs/.vitepress/config.mjs`.

Run `npm install` once in this folder. Then run `npm run build:blog` from the repository root. The generated static site is written to `/blog`, ready to commit and push to `master` for GitHub Pages.
